# Persona Desk · Blue

*The season below the surface* — the Persona Desk synthetic trading season,
watched through three new 3D worlds. Same universe, same seeded market, same
manager rule books as `Persona Desk · Worlds`; a different lens on the same
numbers.

## Worlds

- **Deep Sea** — traders are submersibles over an abyssal plain. Altitude is
  the season so far: above the blue 0% waterline is profit, below is drawdown.
  The winch line's buoy glows with each day's result; benched traders are
  hauled up to the red dry-dock ring; blue sonar rings ping the manager's
  cuts, benches and promotions.
- **Weather Systems** — traders are storm cells over a night map. Cells swell
  with recent volatility and flash with the day's result. The manager is the
  wind: capital pulls a cell toward the calm eye; benched cells drift to the
  doldrums; lightning bolts strike where the manager acted.
- **Night Reef** — traders are schools of reef fish. School spread tracks
  allocation, schools dart on strong days, benched schools rest in the red
  rest cove. The manager is a turtle gliding above the school it favours.

## Run

Static site, no build step.

```bash
python3 -m http.server 8123
# open http://127.0.0.1:8123/
```

Deep links: `#pdb=<world>&pdbd=<day>` (e.g. `#pdb=weather&pdbd=70`),
worlds: `sea`, `weather`, `reef`.

## Test

The simulation engine (`engine.js`, copied verbatim from the Persona Desk
artifact) runs in Node:

```bash
node test_engine.js
```

## Layout

- `index.html` — page, HUD wiring, the three Three.js worlds
- `engine.js` — seeded market + manager rule engine (UMD, no DOM)
- `test_engine.js` — engine smoke tests (determinism, shapes, sane outputs)

---

Illustrative simulation. Trader returns are generated by a seeded synthetic
market and are not live, paper or backtested results. Manager behaviour is
each manager's real rule set applied to those returns. Not investment advice.
